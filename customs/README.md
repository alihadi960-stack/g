# شيك المطالبة الجمركية

صفحة ويب: ترفع صورة (أو PDF) شهادة الإفراج الجمركية من نافذة + إيصال المطالبة،
Claude يستخرج البيانات، تراجعها، وتتضاف كبلوك جديد في شيت **"شيك مطالبة"** بنفس المعادلات.

## التشغيل
- الصفحة على `/customs/` (مع Firebase Hosting الموجود).
- أول مرة: **الإعدادات** ← حط Claude API key (بيتحفظ على الجهاز بس).

## الخطوات
1. افتح ملف الإكسيل بتاعك (أو "ملف جديد").
2. ارفع كل صفحات الشهادة + إيصال المطالبة ← **استخراج البيانات**.
3. راجع الأرقام: علامة ✓ يعني الرقم المحسوب مطابق للمكتوب في الشهادة.
4. **أضف للشيت** (تقدر تضيف كذا شهادة) ← **تحميل ملف الإكسيل**.

## المعادلات (نفس الشيت الأصلي)
| العمود | المعادلة |
|---|---|
| D سعر التحويل | `E/B` في أول سطر، وباقي السطور `=$D$أول_سطر` |
| I وعاء الضريبة | `D*F + J` |
| J ضريبة الوارد | `F*D*H` |
| K القيمة المضافة | `I*0.14` |
| L أرباح تجارية | `D*F*0.01` |
| M قيمة الشيك | `L+K+J` |
| صف الإجمالي | `SUM` لـ J..M، و `O = M - N` (الفرق عن المطالبة) |

لتجربته على جهازك من غير سيرفر: افتح `standalone.html` بدبل كليك (بيتولد بـ `python3 customs/build-standalone.py`).

الكود: `sheet.js` (كتابة البلوك في الإكسيل)، `app.js` (الواجهة + الاستخراج).
