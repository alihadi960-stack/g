# nozomeg.com — صفحة هبوط بأسلوب دفترة

صفحة هبوط ثابتة (HTML/CSS/JS بدون أي مكتبات) لنظام **نظم ERP**، مبنية على نفس بنية وإيقاع موقع دفترة.
التحليل التفصيلي لتصميم دفترة في [`../docs/daftra-design-analysis.md`](../docs/daftra-design-analysis.md).

## التشغيل
افتح `index.html` مباشرة في المتصفح، أو شغّل أي خادم ثابت:

```bash
npx http-server nozomeg -p 8080
```

## بنية الصفحة
شريط إعلان → قائمة علوية (مع Mega Menu) → Hero + لوحة تحكم مبنية بـ CSS → شعارات العملاء → شبكة التطبيقات (9) → القطاعات (7 تبويبات) → 3 صفوف مميزات متعرجة → أرقام متحركة → شهادات (سلايدر) → اعتمادات → الأسعار (شهري/سنوي) → أسئلة شائعة → CTA → تذييل → زر واتساب عائم.

## التخصيص السريع
| ماذا | أين |
|---|---|
| الألوان والخط والزوايا | متغيرات `:root` أعلى `css/style.css` |
| اسم العلامة والشعار | عنصر `.logo` في `index.html` (استبدل أيقونة SVG بصورة) |
| النصوص والأسعار | مباشرة في `index.html` (الأسعار في `data-monthly` / `data-yearly`) |
| رقم واتساب | رابط `.wa` في نهاية `index.html` |
| صور المنتج الحقيقية | استبدل `.dash` و`.frame` و`.phones` بصور `<img>` |

## ملاحظات
- الخط Cairo يُحمَّل من Google Fonts مع بدائل نظام عند غياب الإنترنت.
- كل الأيقونات SVG مضمّنة (sprite) بلا مكتبات خارجية.
- متجاوب بالكامل: نقاط الكسر 1100 / 1024 / 900 / 600px.
- يحترم `prefers-reduced-motion`.
